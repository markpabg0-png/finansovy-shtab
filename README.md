# Финансовый штаб

Личный финансовый штаб на GitHub Pages.

## Уведомления о новых фриланс-заказах в Telegram

Лента заказов обновляется workflow `Refresh freelance jobs feed`, а workflow `Telegram notifications for new freelance jobs` проверяет её каждые 15 минут и отправляет только новые объявления в личный чат Telegram. За один запуск отправляется не более пяти объявлений; старые заказы при первом запуске не рассылаются.

Для включения уведомлений один раз добавьте в **Settings → Secrets and variables → Actions → New repository secret**:

- `TELEGRAM_BOT_TOKEN` — токен вашего Telegram-бота от @BotFather (не публикуйте его в коде и чатах).
- `TELEGRAM_CHAT_ID` — ваш личный Telegram ID. Откройте бота и отправьте ему `/start`; свой ID можно посмотреть у @userinfobot.

После добавления секретов откройте **Actions → Telegram notifications for new freelance jobs → Run workflow**. Следующие новые заказы будут приходить автоматически. Если workflow запускается до настройки секретов, а новых объявлений нет, сообщение не отправляется и ошибки из-за отсутствующих секретов не возникает.

Уведомления содержат название, источник, бюджет (если указан), краткое описание и ссылку на исходное объявление.
